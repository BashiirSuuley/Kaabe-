# 🎓 Kaabe — Academic AI Platform

**Kaabe** is a complete AI-powered academic tools platform for university lecturers.
Upload any PDF → get 6 powerful tools instantly.

> *Built for Somalia and beyond — empowering educators with AI.*

## 6 Tools in One Platform

| Tool | Output | Description |
|------|--------|-------------|
| 📊 Lecture Slides | `.pptx` | Formulas, examples, calculations, tables |
| ❓ MCQ Generator | `.docx` | Multiple choice with answers & explanations |
| 📝 Exam Paper | `.docx` | Full Word exam with custom structure & mark scheme |
| 📋 Smart Summary | `.docx` | Key concepts, terms, formulas, mind map |
| 🃏 Flashcards | `.txt` | Interactive flip cards with shuffle |
| 💬 AI Tutor | Chat | Ask anything — responds like a professor |

## Exam Section Types
MCQ · True/False · Short Answer · Long Answer · Calculation · Fill in Blank · Matching · Case Study

## Files needed (just 3)
- app.py
- requirements.txt
- README.md

## Get FREE Gemini API key
1. Go to https://aistudio.google.com/app/apikey
2. Sign in with Google → Create API Key → Copy and paste into Kaabe

## Deploy on Streamlit Cloud (Free)
1. Upload 3 files to GitHub
2. Go to share.streamlit.io → New app → your repo → main file: app.py → Deploy
